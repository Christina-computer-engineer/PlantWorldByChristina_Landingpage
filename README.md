# PlantWorldByChristina_Landingpage
🌿 PlantWorld Landing Page
📌 Project Overview

This is a simple responsive landing page for a plant selling website named PlantWorldByChristina.
It is built using HTML5 and CSS3 and designed to be clean, modern, and mobile-friendly.

🎯 Features
🌱 Responsive landing page design
🧭 Navigation bar with smooth scrolling
🏡 Hero section with heading, text, and button
🪴 Plant product showcase section
📖 About section with image and description
📞 Contact section
📱 Mobile-friendly layout using Flexbox and media queries
🎨 Clean and modern UI design
🛠️ Technologies Used
HTML5
CSS3
Flexbox (layout design)
Media Queries (responsiveness)
